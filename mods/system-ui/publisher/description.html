Seraph UI (modid: seraphui)
Shared client-side UI framework and reusable component library built to match Vintage Story’s native interface aesthetic.
Note for Players: You do not need to configure anything in this mod. Simply drop it into your Mods folder whenever another mod (such as Traders Overhaul or Seraph QoL) requires it. It runs strictly on the client and makes zero gameplay changes on its own.
What Seraph UI Provides
  • Unified Game Aesthetic (SystemUITheme): Shared palette, typography presets, trend formatting, and panel spacing aligned with Vintage Story’s native GUI.
  • Modular Dialog Base (UiDialogBase): Standardizes dialog margins, shaded backgrounds, title bars, and safe partial view refreshes.
  • Reusable UI Elements: Tab strips, inset cards, icon+text buttons, dynamic dividers, passive panels, and rich text helpers.
  • Zero Gameplay Overhead: Adds no blocks, items, entities, or world changes.
Installation & Requirements
Game Version Vintage Story 1.22.0 or compatible
Execution Side Client-side only (safe for multiplayer servers)
How to Install Place seraphui-0.1.0.zip directly into your Vintage Story Mods folder (do not extract).
