Traders Overhaul (modid: tradersoverhaul)
A living trader economy for Vintage Story: universal item selling, archetype specialization, daily demand bonuses, anti-farming saturation, a modern trade window, and a Global Trader Directory.
Early Development Notice: This mod is in an early stage of development and may contain bugs. Please back up your worlds before installing or updating, and report any issues you encounter.
Required Dependency: You must install Seraph UI (seraphui) alongside this mod. Optional live settings are supported via ConfigLib or ModConfig/tradersoverhaul.json.
Core Mechanics & Features
Feature How It Works
Universal Selling & Lot Grouping Sell almost any tradeable item to any trader instead of being limited to 6–10 fixed items. Low-value items automatically bundle into clean whole-gear lots (e.g. 4x → 1 gear), and tool durability or food freshness adjusts value proportionally.
Trader Archetype Affinity Every trader type (Survival Goods, Agriculture, Artisan, Building Materials, Clothing, Furniture, Luxuries, Treasure Hunter, Commodities) pays higher rates for items matching their trade and reduced rates for off-specialty goods.
Daily Wanted Demand Preserves Vintage Story’s periodic trader rotation — items on a trader’s Wanted list grant an extra +20% to +50% bonus and are highlighted directly in the trade window.
Anti-Farming Saturation Repeatedly dumping large volumes of the same item lowers payouts along a smooth diminishing-returns curve (down to a configurable minimum floor) and partially propagates to nearby traders (1500 blocks by default), recovering gradually over in-game days.
Redesigned Trade Window Includes a multi-item shopping cart, clear stock indicators, 5 live appraisal sell slots, net gear balance, and transparent tooltips breaking down Base Value × Affinity × Daily Demand × Saturation.
Global Trader Directory Inspect every trader you have discovered in the world: filter by archetype, compare wanted items, check remaining funds, distance, rotation countdown, and jump to their map marker. Strictly read-only by default so physical travel remains meaningful.
Controls
K Open / close the Known Traders Directory (rebindable in Controls)
Left / Right Click In the trade window: Left-click stock adds +1 to cart; Right-click removes -1
Configuration Highlights
  • Economy Presets: Stingy (higher buy prices, 75% sell payout), Balanced (default 100%), or Businessman (120% sell payout).
  • Directory Sync Mode: Last Visited Snapshot (default, rewards revisiting traders) or Live Known Traders (updates automatically as days pass).
  • Saturation Scope: Nearby Partial (default), Local Only, or Global — with tunable spillover radius, recovery rate, and floor.
  • Optional Inventory Valuation: Toggle ShowValuationInInventoryTooltip to preview base values on normal inventory tooltips.
