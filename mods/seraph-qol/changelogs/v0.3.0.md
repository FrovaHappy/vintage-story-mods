# Release v0.3.0 (2026-11-24)

### Added
- **Slot selection overlay (`InventoryButtonsComposer`)**: Added a custom rustic organic parchment border SVG (`slot-selection.svg`) for matching item slot highlighting.

### Changed
- **Slot status indicators (`SlotIndicatorRenderer`, `SlotIndicatorPlanner`)**: Redesigned food freshness and liquid volume indicators to render behind item models across 100% of slot bounds using a sage green and water blue palette.
- **Slot badge layout (`InventoryButtonsComposer`)**: Moved favorite star badge to top-right corner and slot lock badge to bottom-left corner to keep the item stack count unobscured.
- **Favorite toggle button (`SvgIconButton`)**: Removed yellowish active backdrop on the favorite mode title-bar toggle button for a clean translucent highlight.

### Fixed
- **Perishable food ratio calculation (`SlotIndicatorPlanner`, `SlotIndicatorRenderer`)**: Fixed an issue where fresh food was prematurely treated as spoiling due to invalid transitioned hours checking, accurately reflecting each food's unique lifespan and freshness.
- **Slot background bounds clipping (`SlotIndicatorRenderer`)**: Fixed background indicator dimensions using active scissor bounds to ensure 100% full-slot coverage instead of small centered insets.
