# Release v0.2.0 (2026-11-24)

- **Tighter anti-farming saturation defaults (`WorldSaturationRegistry`)**: Reduced `SaturationMinFloor` to 0.10, lowered `SaturationS50` to 15.0 GEV and raised `SaturationCurvePower` to 1.6 to block Tier 3–4 items at lot 1 faster.
- **Per-item price overrides (`ItemValuationRegistry`)**: Added `ItemValueOverrides` dictionary to the mod config for custom base prices via ConfigLib JSON, with exact-key and wildcard (`*`-suffix) prefix resolution.
- **Saturation recovery rate**: Raised `SaturationRecoveryPerDay` from 6.0 to 8.0 GEV/day to compensate for the tighter floor.
- **Balance documentation**: Updated `balance.md` saturation examples and curve parameters to the new defaults (`S50 = 15.0`, `p = 1.6`, `M_min = 0.10`).
- Corrected the saturation multiplier example in `balance.md` (`Caso 3`) to use the new defaults.
