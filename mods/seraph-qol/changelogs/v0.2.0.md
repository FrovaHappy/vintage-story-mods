# Release v0.2.0 (2026-11-22)

### Added
- **Inventory selector hatching (`InventoryButtonsComposer`)**: Warm brown/bronze diagonal hatch on inactive slots while Favorite or Lock mode is active, keeping both toggle buttons visually synchronized.
- **Improved Handbook Recipes (`HandbookRecipeService`, `SeraphQoLHandbookPatches`, `ServerInventoryExecutor`)**: Added VS 1.22-compatible handbook mouse-wheel variant scrolling, `+` / `*` crafting grid auto-fill buttons (with nearby closed-chest scanning/pulling, locked-slot protection and `Shift` chest bypass), real-time red missing-ingredient highlighting, non-consumed tool wrench badges with durability cost tooltips, and item max stack size tooltips.
